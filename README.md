## Estrategia de Ramas (Branch Strategy)

```
Main
├── Produccion
├── Stagg
├── QA
└── Dev
```

| Rama        | Propósito                                      |
|-------------|------------------------------------------------|
| Main        | Rama principal del repositorio                 |
| Produccion  | Código listo para producción                   |
| Stagg       | Ambiente de staging (pre-producción)           |
| QA          | Ambiente de pruebas y control de calidad       |
| Dev         | Desarrollo activo de nuevas funcionalidades    |

## Proyecto Demo

Aplicación de consola .NET ubicada en la carpeta `HolaMundo/`.

### Ejecutar

```bash
cd HolaMundo
dotnet run
```
